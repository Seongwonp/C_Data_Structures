# Graph (그래프)

## 그래프 기본 개념

```
     정점(Vertex): A, B, C, D, E
     간선(Edge): 정점 사이의 연결

     [인접 리스트]          [인접 행렬]
     A → B, C              A B C D E
     B → A, D, E       A [ 0 1 1 0 0 ]
     C → A, D          B [ 1 0 0 1 1 ]
     D → B, C          C [ 1 0 0 1 0 ]
     E → B             D [ 0 1 1 0 0 ]
                       E [ 0 1 0 0 0 ]
```

---

## BFS / DFS

```
그래프:
    1 - 2 - 4
    |   |
    3 - 5

BFS (너비 우선, 큐 사용):
  방문: 1 → 2 → 3 → 4 → 5
  층별로 탐색, 최단 경로 찾기에 적합

DFS (깊이 우선, 스택/재귀):
  방문: 1 → 2 → 4 → 5 → 3
  한 방향 끝까지, 미로 탈출 / 사이클 탐지에 적합
```

## 다익스트라 (Dijkstra)

단일 출발지 최단 경로, 음수 가중치 불가, **O(V²)** (인접 행렬)

```
        4       8
    0 ─── 1 ─── 7
    │\    │\    │
   3│ \8  │11 1│  \9
    │  \  │  \ │   \
    2   7─6   4─5   3
    │  /  │  / │
   7│ /2  │4  /10
    │/    │/
    8     5

출발: 0
dist: [0, 4, 12, 19, 21, 11, 9, 8, 14]

알고리즘:
  1. dist[start]=0, 나머지 INF
  2. 미확정 노드 중 dist 최솟값 u 선택
  3. u 인접 노드 v: dist[u]+w < dist[v] 이면 갱신
  4. u 확정 처리 → 반복
```

## 플로이드-워셜 (Floyd-Warshall)

모든 쌍(all-pairs) 최단 경로, 음수 가중치 가능, **O(V³)**

```
점화식: dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])

k=0,1,...,n-1 순서로 중간 경유지 추가하며 갱신

초기:        k=0 경유:     k=1 경유:
  0  3  ∞  7      0  3  ∞  7      0  3  5  7
  8  0  2  ∞  →   8  0  2 15  →   8  0  2 15
  5  ∞  0  1      5  8  0  1      5  8  0  1
  2  ∞  ∞  0      2  5  ∞  0      2  5  7  0
```

## 최소 신장 트리 (MST)

모든 노드를 연결하는 **최소 비용** 트리 (간선 V-1개)

### 크루스칼 (Kruskal) — O(E log E)

```
① 간선을 가중치 오름차순 정렬
② Union-Find로 사이클 없으면 간선 선택

Union-Find:
  find(x): 루트 탐색 (경로 압축)
  union(x,y): 두 집합 합치기

  [선택 순서]
  (1-2):1 → (3-5):1 → (1-3):2 → (3-4):2 → (4-6):3  총 9
```

### 프림 (Prim) — O(V²) (인접 행렬)

```
① 임의 노드에서 시작, MST 집합에 추가
② MST에서 연결 가능한 간선 중 최솟값 선택
③ 선택된 노드를 MST에 추가 → 반복

  key[] 배열로 각 노드와 MST 사이 최소 거리 유지
```
