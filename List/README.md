# List (연결 리스트)

## 단순 연결 리스트 (Singly Linked List)

각 노드가 다음 노드의 포인터를 가짐.

```
head
 ↓
[1 | →] → [2 | →] → [3 | →] → [4 | NULL]

노드 구조:
  struct Node {
      int data;
      struct Node* next;
  };
```

### 삽입/삭제

```
삽입 (앞에):
  new → [0 | →] → [1 | →] → [2 | →] → NULL
  head = new

삽입 (중간, 2번 뒤):
  [1 | →] → [2 | →] → [new| →] → [3 | NULL]
                        ↗
             new->next = node->next
             node->next = new

삭제 (2번):
  prev->next = target->next
  free(target)
```

## 이중 연결 리스트 (Doubly Linked List)

이전/다음 양방향 포인터.

```
NULL ← [1 | ↔ | →] ↔ [2 | ↔ | →] ↔ [3 | ↔ | NULL]
        ↑ prev  next ↑

장점: 역방향 탐색 가능, 삭제 시 prev 탐색 불필요
단점: 포인터 2개로 메모리 증가
```

---

## 원형 이중 연결 리스트

마지막 노드가 첫 노드와 연결 (sentinel/dummy node 활용).

```
     head(dummy)
      ↓
  ┌→ [D] ↔ [1] ↔ [2] ↔ [3] ←┐
  └──────────────────────────┘

장점:
  - 경계 조건(head/tail) 처리 단순화
  - 앞/뒤 삽입/삭제 모두 O(1)
  - 리스트가 비어도 head는 항상 존재
```

## 배열 vs 연결 리스트

| 항목 | 배열 | 연결 리스트 |
|------|------|------------|
| 접근 | O(1) 인덱스 | O(n) 순차 |
| 삽입(앞) | O(n) 이동 | O(1) |
| 삽입(뒤) | O(1) | O(n) or O(1)* |
| 삭제 | O(n) 이동 | O(1)** |
| 메모리 | 연속, 캐시 효율↑ | 포인터 오버헤드 |
| 크기 | 고정(정적) | 동적 |

> *tail 포인터 유지 시 / **이전 노드 알 때

## 희소 배열 (Sparse Array)

대부분이 0인 행렬을 연결 리스트로 효율적 저장.

```
일반 행렬 (4×4, 16개 저장):
[5, 0, 0, 0]
[0, 8, 0, 0]
[0, 0, 3, 0]
[0, 6, 0, 0]

희소 배열 (4개만 저장):
  (0,0,5) → (1,1,8) → (2,2,3) → (3,1,6)

메모리 절약: 0이 많을수록 효율적
```
