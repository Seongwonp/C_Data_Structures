# Stack (스택)

## 개념

**LIFO** (Last In, First Out): 나중에 들어온 것이 먼저 나감.

```
push(1) → push(2) → push(3)

   top
    ↓
  [ 3 ]
  [ 2 ]
  [ 1 ]

pop() → 3 반환
pop() → 2 반환
```

---

## 스택 활용

### 괄호 검사

```
입력: "( { [ ] } )"

push '(':  [ ( ]
push '{':  [ (, { ]
push '[':  [ (, {, [ ]
만남 ']':  pop → '[' 매칭 ✓  [ (, { ]
만남 '}':  pop → '{' 매칭 ✓  [ ( ]
만남 ')':  pop → '(' 매칭 ✓  [ ]
스택 비었음 → 올바른 괄호 ✓
```

### 후위 표기식 (Postfix) 계산

```
중위: 3 + 4 * 2  →  후위: 3 4 2 * +

토큰   스택
  3  → [3]
  4  → [3, 4]
  2  → [3, 4, 2]
  *  → [3, 8]      (4*2=8)
  +  → [11]        (3+8=11)

결과: 11
```

### 중위 → 후위 변환 (연산자 우선순위)

```
우선순위: * / > + -

A + B * C - D

토큰   스택    출력
  A  →  []   → A
  + →  [+]   → A
  B →  [+]   → A B
  * →  [+,*] → A B
  C →  [+,*] → A B C
  - →  [-]   → A B C * +   (* 먼저 pop, + pop)
  D →  [-]   → A B C * + D
end→  []    → A B C * + D -
```

## 재귀 호출 스택

```
factorial(3) 호출 스택:
  ┌─────────────────┐ ← 최상단
  │ factorial(1)=1  │
  ├─────────────────┤
  │ factorial(2)=?  │
  ├─────────────────┤
  │ factorial(3)=?  │
  └─────────────────┘ ← 바닥

반환 순서: 1 → 2×1=2 → 3×2=6
```

## 시간 복잡도

| 연산 | 복잡도 |
|------|--------|
| push | O(1) |
| pop | O(1) |
| peek (top 확인) | O(1) |
