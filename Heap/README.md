# Heap (힙)

## 개념

**완전 이진 트리** + **힙 성질**: 부모가 항상 자식보다 크거나(최대 힙) 작다(최소 힙).

```
최대 힙 (Max Heap):        최소 힙 (Min Heap):
        10                         1
       /  \                       / \
      9    8                     2   3
     / \  / \                   / \ / \
    7  6  5  4                 4  5 6  7

규칙: parent >= children      규칙: parent <= children
```

---

## 배열로 표현

```
인덱스:     1   2   3   4   5   6   7
최대 힙: [ _, 10,  9,  8,  7,  6,  5,  4 ]
              ↑
          index 1부터 사용 (0번 비움)

부모 인덱스:   i / 2
왼쪽 자식:     2 * i
오른쪽 자식:   2 * i + 1

예: index=3(값=8)
  부모:        3/2 = 1 (값=10) ✓
  왼쪽 자식:   3*2 = 6 (값=5)
  오른쪽 자식: 3*2+1 = 7 (값=4)
```

---

## 삽입 (Push Up)

```
10에 11 삽입:

① 맨 끝에 추가:
   [10, 9, 8, 7, 6, 5, 4, 11]
                            ↑ 새 원소

② 부모와 비교하며 위로 올라감 (sift up):
   11 > 7 → swap: [10, 9, 8, 11, 6, 5, 4, 7]
   11 > 9 → swap: [10, 11, 8, 9, 6, 5, 4, 7]
   11 > 10 → swap: [11, 10, 8, 9, 6, 5, 4, 7]
```

---

## 삭제 (Pop, 최댓값 추출)

```
최대 힙: [10, 9, 8, 7, 6, 5, 4]

① 루트(10) 추출
② 마지막 원소(4)를 루트로 이동:
   [4, 9, 8, 7, 6, 5]

③ 자식 중 큰 값과 비교하며 아래로 내려감 (sift down):
   4 < 9 → swap: [9, 4, 8, 7, 6, 5]
   4 < 7 → swap: [9, 7, 8, 4, 6, 5]
   4 > 5 → stop (리프)
   
결과: [9, 7, 8, 4, 6, 5], 반환값=10
```

---

## 힙 정렬 (Heap Sort)

```
① 배열 전체 heapify → 최대 힙 구성: O(n)
② n번 pop → 오름차순 정렬: O(n log n)
전체: O(n log n), 추가 공간 O(1)
```

---

## 우선순위 큐 (Priority Queue)

```
힙으로 구현한 우선순위 큐:
  - OS 작업 스케줄링
  - 다익스트라 최단 경로
  - 허프만 코딩 (압축)
  - A* 탐색
```

---

## 시간 복잡도

| 연산 | 복잡도 |
|------|--------|
| 삽입 | O(log n) |
| 최대/최소 조회 | O(1) |
| 삭제(max/min) | O(log n) |
| 힙 구성(heapify) | O(n) |
