# 📚 C 자료구조 & 알고리즘 실습 저장소

이 저장소는 컴퓨터 과학 및 소프트웨어 공학 학습의 일환으로  
**C 언어**를 활용해 구현한 다양한 자료구조 및 알고리즘 실습 코드들을 포함하고 있습니다.

---

## 📁 폴더 구성

| 폴더명         | 설명 |
|----------------|------|
| CardConverter  | 숫자 → 카드 문자열 변환 로직 등 간단한 변환 예제 |
| Graph          | 그래프 구조 및 탐색 (BFS / DFS) |
| Hash           | 해시 테이블 구현 및 활용 |
| Heap           | 최소 힙 / 최대 힙 연산 |
| List           | 단일 / 이중 연결 리스트 구현 |
| Queue          | 배열 기반 및 연결 리스트 기반 큐 |
| Recursive      | 재귀 기반 알고리즘 예제 |
| Set            | 집합 연산 (합집합, 교집합 등) |
| Sort           | 다양한 정렬 알고리즘 |
| Sosu           | 소수 판별 및 관련 알고리즘 |
| Stack          | 스택 자료구조 구현 |
| Tree           | 이진 트리 및 순회 알고리즘 |

---

## 💭 회고

이번 실습을 통해 자료구조와 알고리즘을 직접 구현해보면서  
단순히 개념을 이해하는 것을 넘어, 실제로 어떻게 동작하는지를 몸소 체험할 수 있었습니다.

처음에는 연결 리스트나 스택 같은 구조도 낯설게 느껴졌지만,  
하나씩 코드를 작성하고 테스트해보면서 점점 익숙해졌고,  
특히 포인터를 다루는 과정에서 C 언어의 특성과 메모리 흐름에 대해 많이 배울 수 있었습니다.

그래프 탐색이나 정렬 알고리즘을 구현할 때는  
단순히 결과를 내는 것보다 어떤 방식이 더 효율적인지 고민하게 되었고,  
그 과정에서 알고리즘의 시간 복잡도나 구조적 설계에 대한 감각도 조금씩 생긴 것 같습니다.

무엇보다도, 각 폴더별로 기능을 나누고 예제를 독립적으로 실행할 수 있도록 구성하면서  
코드를 정리하고 구조화하는 습관을 기를 수 있었던 점이 개인적으로 가장 의미 있었습니다.

앞으로는 이번에 익힌 자료구조들을 활용해서  
간단한 프로젝트나 문제 해결에 직접 적용해보고 싶습니다.  
예를 들어, 텍스트 분석기나 간단한 게임 로직처럼  
자료구조가 실제 기능으로 연결되는 경험을 해보면 좋을 것 같습니다.

짧은 시간이었지만, 실습을 통해 많은 것을 배울 수 있었고  
무엇보다도 C 언어로 직접 구현해보는 과정이 재미있고 보람 있었습니다.
