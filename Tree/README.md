# Tree (트리)

## 이진 탐색 트리 (BST)

각 노드의 **왼쪽 < 현재 < 오른쪽** 조건을 유지하는 트리.

```
        삽입 순서: 5, 3, 7, 1, 4, 6, 8

              5
            /   \
           3     7
          / \   / \
         1   4 6   8

탐색 예: 4 찾기
  5 → 오른쪽? 아니 (4<5) → 왼쪽
  3 → 오른쪽? 예 (4>3) → 오른쪽
  4 → 일치! ✓
```

| 연산 | 평균 | 최악 (편향) |
|------|------|------------|
| 탐색 | O(log n) | O(n) |
| 삽입 | O(log n) | O(n) |
| 삭제 | O(log n) | O(n) |

### 삭제 3가지 케이스
```
케이스 1: 자식 없음 (leaf)
  → 그냥 삭제

케이스 2: 자식 1개
  → 부모와 자식을 직접 연결

케이스 3: 자식 2개
  → 오른쪽 서브트리의 최솟값(inorder successor)으로 대체
```

## AVL 트리

BST에 **높이 균형** 조건 추가: 모든 노드의 두 서브트리 높이 차 ≤ 1  
→ 탐색/삽입/삭제 항상 **O(log n)** 보장

### 회전(Rotation) 4가지

```
LL 회전 (오른쪽으로 회전):
        z                y
       / \              / \
      y   D    →       x   z
     / \              / \ / \
    x   C            A  B C  D

RR 회전 (왼쪽으로 회전):
    z                  y
   / \                / \
  A   y      →       z   x
     / \            / \ / \
    B   x          A  B C  D

LR 회전 (왼쪽 → 오른쪽):
    z             z             x
   /             /             / \
  y     →       x      →      y   z
   \           /
    x          y

RL 회전 (오른쪽 → 왼쪽):
  z               z               x
   \               \             / \
    y      →        x    →      z   y
   /                 \
  x                   y
```

### 균형 인수 (Balance Factor)
```
BF = height(왼쪽) - height(오른쪽)

BF >  1 → 왼쪽 과중 → 오른쪽 회전 필요
BF < -1 → 오른쪽 과중 → 왼쪽 회전 필요
```

## 이진 트리 순회

```
        1
       / \
      2   3
     / \
    4   5

전위(Preorder):  1 → 2 → 4 → 5 → 3  (루트 → 왼 → 오)
중위(Inorder):   4 → 2 → 5 → 1 → 3  (왼 → 루트 → 오) ← BST는 정렬 순서
후위(Postorder): 4 → 5 → 2 → 3 → 1  (왼 → 오 → 루트)
```
