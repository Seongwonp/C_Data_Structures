# Sort (정렬)

## 기본 정렬 비교

| 알고리즘 | 평균 | 최악 | 공간 | 안정성 |
|----------|------|------|------|--------|
| 버블 정렬 | O(n²) | O(n²) | O(1) | 안정 |
| 선택 정렬 | O(n²) | O(n²) | O(1) | 불안정 |
| 삽입 정렬 | O(n²) | O(n²) | O(1) | 안정 |
| 병합 정렬 | O(n log n) | O(n log n) | O(n) | 안정 |
| 퀵 정렬   | O(n log n) | O(n²) | O(log n) | 불안정 |
| 힙 정렬   | O(n log n) | O(n log n) | O(1) | 불안정 |
| 계수 정렬 | O(n+k) | O(n+k) | O(k) | 안정 |
| 기수 정렬 | O(d(n+k)) | O(d(n+k)) | O(n+k) | 안정 |

## 퀵 정렬 (Quick Sort)

```
배열: [3, 6, 8, 10, 1, 2, 1]
피벗: 1 (마지막 원소)

  [3, 6, 8, 10, 1, 2, 1]
               ↑ 피벗
  → [1] | [1] | [3, 6, 8, 10, 2]
                    ↑ 피벗=2
  → [1,1] | [2] | [3,6,8,10]
  
최종: [1, 1, 2, 3, 6, 8, 10]
```

## 병합 정렬 (Merge Sort)

```
[38, 27, 43, 3, 9, 82, 10]
        ↙              ↘
[38, 27, 43]        [3, 9, 82, 10]
  ↙       ↘           ↙         ↘
[38]   [27,43]     [3,9]      [82,10]
         ↙↘           ↙↘         ↙↘
       [27][43]     [3][9]    [10][82]
         ↘↙           ↘↙         ↘↙
       [27,43]       [3,9]     [10,82]
           ↘           ↙
         [27,38,43]  [3,9,10,82]
               ↘       ↙
          [3,9,10,27,38,43,82]
```

## 힙 정렬 (Heap Sort)

```
① 배열 → 최대 힙으로 변환 (heapify)
② 루트(최댓값)를 끝으로 보내고 힙 크기 줄임
③ 반복

[4, 10, 3, 5, 1]
        ↓ heapify
[10, 5, 3, 4, 1]  ← 최대 힙
        ↓ 루트(10) ↔ 끝
[5, 4, 3, 1, | 10]
        ↓ 반복
[1, 3, 4, 5, 10]  ✓ 정렬 완료
```

## 계수 정렬 (Counting Sort)

```
배열: [4, 2, 2, 8, 3, 3, 1]

① count[] 배열에 등장 횟수 기록
   idx:   0  1  2  3  4  5  6  7  8
   count: 0  1  2  2  1  0  0  0  1

② 누적합 계산
   count: 0  1  3  5  6  6  6  6  7

③ 뒤에서부터 원본 스캔하여 output[] 배치
   결과: [1, 2, 2, 3, 3, 4, 8]

특징: 정수, 범위(k) 작을 때 O(n+k) 선형 시간
```

---

## 기수 정렬 (Radix Sort)

```
배열: [170, 45, 75, 90, 802, 24, 2, 66]

1의 자리 기준 계수정렬:
  [170, 90, 802, 2, 24, 45, 75, 66]

10의 자리 기준:
  [802, 2, 24, 45, 66, 170, 75, 90]

100의 자리 기준:
  [2, 24, 45, 66, 75, 90, 170, 802]  ✓

d자리 수 → d번 계수정렬 → O(d·(n+k))
```
