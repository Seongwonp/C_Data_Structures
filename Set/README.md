# Set (집합 / Union-Find)

## Union-Find (서로소 집합, Disjoint Set Union)

서로 겹치지 않는 집합들을 효율적으로 관리.  
주로 **그래프 사이클 탐지**, **MST(크루스칼)** 에 활용.

```
초기 상태: {0}, {1}, {2}, {3}, {4}
parent: [0, 1, 2, 3, 4]

union(0, 1):  parent[0] = 1  → {0,1}, {2}, {3}, {4}
union(2, 3):  parent[2] = 3  → {0,1}, {2,3}, {4}
union(1, 3):  parent[1] = 3  → {0,1,2,3}, {4}

find(0): 0→1→3  (루트=3)
find(2): 2→3    (루트=3)
find(0) == find(2) → 같은 집합!
```

---

## 경로 압축 (Path Compression)

```
압축 전:
  find(0): 0 → 1 → 3 → 5 (루트)

압축 후 (재귀 도중 parent 갱신):
  parent[0] = 5
  parent[1] = 5
  parent[3] = 5

다음 find(0): 0 → 5  (바로!)
```

---

## 랭크 기반 합치기 (Union by Rank)

```
항상 낮은 트리를 높은 트리 아래에 붙임 → 트리 높이 최소화

rank[A]=1, rank[B]=2:
   A          B
  /     →   / \
           A   ...
```

---

## 시간 복잡도

| 연산 | 복잡도 |
|------|--------|
| find (경로 압축) | O(α(n)) ≈ O(1) |
| union (랭크 기반) | O(α(n)) ≈ O(1) |

> α(n): 아커만 함수의 역함수, 실질적으로 4 이하

---

## 사이클 탐지

```
그래프 간선 추가 시:
  두 노드의 find() 결과가 같으면 → 사이클 발생!
  다르면 → union() 후 간선 추가

크루스칼 알고리즘에서 MST 구성 시 핵심 역할
```
